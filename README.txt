PROYEK DATA MINING KNN — STREAMLIT

Versi ini sudah disesuaikan untuk Streamlit Cloud dan tidak menggunakan tkinter.

Isi:
- app.py: aplikasi web Streamlit
- requirements.txt: library yang diperlukan
- data_pasien.csv: dataset 10 pasien
- data_pasien.xlsx: dataset dalam format Excel
- README.txt: panduan

Jalankan di komputer:
1. Ekstrak ZIP.
2. Buka folder di VS Code.
3. Jalankan di terminal:
   pip install -r requirements.txt
   streamlit run app.py

Jalankan di Streamlit Cloud:
1. Unggah file-file di folder ini ke repository GitHub.
2. Buat aplikasi baru di Streamlit Community Cloud.
3. Pilih repository dan set Main file path menjadi app.py.
4. Klik Deploy.

PENTING: app.py, requirements.txt, dan data_pasien.csv harus berada pada direktori yang sama.

Data pasien baru awal: Usia 42, BMI 28.5, Glukosa 130, Tekanan Darah 128,
Riwayat Keluarga 1. Nilai K awal 3.
Dataset adalah contoh latihan dan bukan alat diagnosis medis.
